# tda-uabc

Podemos correr el script para los diferentes viajes (`tripID`):
- `0A7_01`
- `H51_08`
- `H52_07`

```bash
python experimentos_TDA_giotto-tda.py --input trip_<tripID>.csv --output diagrama_<tripID>.png
```

Por ejemplo:

```bash
python experimentos_TDA_giotto-tda.py --input trip_H51_08.csv --output diagrama_H51_08.png
```
